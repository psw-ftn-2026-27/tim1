Integracija putanje na deljenoj mapi

Uvezi Map u imports komponente. Sledeći primer koristi putanju iz probne stranice. 

import { signal } from '@angular/core';
import { Map } from '../../../shared/ui/map/map';
import type { MapRouteRequest } from '../../../shared/ui/map/map';

Opcioni ulaz routeRequest prima najmanje dve ključne tačke u redosledu obilaska kroz points. Koordinate latitude i longitude su u decimalnim stepenima. mode je Walking, Bicycle ili Car. Ulaz pins određuje koje lokacije imaju oznaku na mapi. 

protected readonly route: MapRouteRequest = {
  points: [
    { latitude: 45.254891, longitude: 19.852782 },
    { latitude: 45.257046, longitude: 19.851583 },
    { latitude: 45.252182, longitude: 19.862732 },
  ],
  mode: 'Walking',
};
protected readonly lengthKm = signal<number | null>(null);
<app-map
  [pins]="route.points"
  [routeRequest]="route"
  (routeLengthKm)="lengthKm.set($event)"
/>

Izlaz routeLengthKm emituje nezaokruženu numeričku dužinu u kilometrima, izračunatu iz iscrtane putanje. Vrednost null označava da dužina trenutno nije dostupna, na primer tokom traženja nove rute ili posle greške. Formatiranje za prikaz pripada stranici koja koristi mapu.

Izostavi routeRequest za prikaz samo pinova. Kada se promene tačke ili način kretanja, prosledi nov objekat. Mapa primenjuje rezultat poslednjeg zahteva.

Pružalac je FOSSGIS OSRM. Adrese profila su u src/app/shared/ui/map/routing-profiles.ts.

OSRM vezuje ključnu tačku za pristupačan segment mreže za izabrani način kretanja. Pin ostaje na prosleđenoj lokaciji, pa linija može proći pored njega ako je van te mreže. Za automobilsku rutu postavi ključne tačke na mesta do kojih se može stići automobilom.
