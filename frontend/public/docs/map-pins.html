Prikaz pinova na deljenoj mapi

Primer uvoza iz probne stranice src/app/core/examples/map-pins/map-pins.ts. 

import { Map } from '../../../shared/ui/map/map';
import type { MapPin } from '../../../shared/ui/map/map';

Dodaj Map u imports komponente koja prikazuje mapu. Ako je komponenta u drugom direktorijumu, prilagodi relativnu putanju.

Prosledi listu koordinata kao obavezan ulaz pins. Stavka tipa MapPin ima numerička polja latitude i longitude u decimalnim stepenima. 

protected readonly pins: readonly MapPin[] = [
  { latitude: 45.2551, longitude: 19.8448 },
  { latitude: 45.2572, longitude: 19.8512 },
];
<app-map [pins]="pins" />

Kada se lista promeni, mapa prikazuje nove pinove i prilagođava pogled. Prazna lista prikazuje podlogu bez pinova. Ovaj prikaz omogućava pomeranje i zumiranje mape.

Podloga se učitava sa OpenStreetMap-a. Kada nijedna tražena pločica podloge ne može da se učita, uz mapu se pojavljuje poruka o grešci.

Izbor lokacije

Postavi selectionEnabled na true da omogućiš izbor. Prvi klik bez povlačenja postavlja pin izbora, a sledeći ga premešta. Izlaz locationSelected odmah šalje MapPin. Povlačenjem se pomera prikaz mape. Kada je ulaz izostavljen ili je false, klik ne menja izbor. 

import { signal } from '@angular/core';

// U klasi stranice
protected readonly selectedLocation = signal<MapPin | null>(null);
<app-map
  [pins]="pins"
  [selectionEnabled]="true"
  (locationSelected)="selectedLocation.set($event)"
/>
<label for="latitude">Geografska širina</label>
<input id="latitude" readonly [value]="selectedLocation()?.latitude ?? ''" />
<label for="longitude">Geografska dužina</label>
<input id="longitude" readonly [value]="selectedLocation()?.longitude ?? ''" />
